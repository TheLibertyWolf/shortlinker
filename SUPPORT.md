# Support

- Read the README and the architecture, API, operations, and security documentation first.
- Use the GitHub bug template for a reproducible defect.
- Use the feature template for a proposed improvement.
- Follow [SECURITY.md](SECURITY.md) exclusively for vulnerabilities.

Community support cannot guarantee compatibility with every reverse proxy,
WordPress extension, network policy, or external destination. Never publish
tokens, passwords, raw visitor data, database exports, or private URLs in an issue.
